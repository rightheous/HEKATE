# HEKATE

HEKATE is a bounded, auditable agent control plane. For the supported local
Qwen setup, start with the [local quickstart](docs/local-quickstart.md).

Local mode is an explicitly selected candidate profile for a private loopback
runtime. Production dispatch remains disabled. HTTP product APIs, operator
recovery for unknown executions, and hosted-provider dispatch are outside the
current scope. The recorded Phase 6F Goal-wide generation limit was exceeded;
the personal profile below is a separate implementation path and does not
change that historical result.

For the owner-focused interactive CLI, use the [personal local guide](docs/personal-use.md)
and the `config/personal-local.example` profile. The existing simple and
Phase 6F verification instructions remain in the [local quickstart](docs/local-quickstart.md).
